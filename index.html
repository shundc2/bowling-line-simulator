セット(投球・レーン設定)

利き手: フックの曲がる方向とポケットが切り替わります。板・スパットの数え方も利き手基準になります(右投げ=右から数えて1枚目、左投げ=左から数えて1枚目)。どちらもポケットは17〜18枚付近です。
パターン: クラウン=中央が最も濃く、板5〜35の範囲だけにオイルがあり外側は完全ドライ / フラット=全面均一(難) / ブロック=内側だけ濃く外は完全ドライ。

全体図の見やすさ調整。実際のレーンは幅1:長さ18ととても細長いため、横方向だけ引き伸ばして表示します(距離・板・軌道の関係は実寸のまま)。

15

回転量のイメージ。0=ストレート、5=平均的なフックボール、8以上=ハイレブ。オイルが切れた地点(◯印)から鋭く曲がります。

30

投球アニメーションの速さに加えて、ラインの曲がり方にも影響します。遅いほどレーンと接している時間が長くなりよく曲がり、速いほど曲がりにくくなります。

投球アニメーションの速さ。一般的なアベレージボウラーで約25〜30km/h、プロで32km/h前後です。

40

オイルが塗られている距離。ハウスコンディションは38〜42ft前後。短いほど手前から曲がり始めます。

6

オイルの濃さ。9〜10=メンテ直後のフレッシュ / 6〜7=一般的 / 4〜5=数ゲーム後 / 2以下=枯れたレーン。少ないほど全体に曲がりやすくなります。

重量: 重いほど衝突で伝わる運動量が大きく、かつピンを抜けた後の減速も小さいため、ピンアクション(物理演算)でのキャリー(全倒れやすさ)が実際の傾向に近い形で上がります。
カバーストック: パールが基準です。ソリッド=オイルを掴みやすくパールより早く強めに曲がる / ウレタン=総じて曲がりは穏やかで滑らかな弧を描きます。
RG: 中RGが基準。低RG=早めに転がり出しやすくフックの立ち上がりが早い / 高RG=手前でスキップし奥目で反応します(内部的にオイル長を短め/長めにずらして再現)。
フレア: track flare(転がり半径のズレ)の大きさ。標準が基準で、強いほどオイルが切れた後の曲がりが鋭くなります。カバー・RG・フレアを変えるとフックの効き方も変わるので、レーン図をなぞってブレイクポイントを再調整するのがおすすめです。

420rpm

回転数(フックの強さと連動)。目安: アベレージ250〜350rpm / 上級者350〜450rpm / ハイレブ450rpm以上。フックの強さスライダーとお互いに連動して動きます。

45°

0°=フルローラー寄り(なめらか・早めに反応・総フック量は控えめ) / 90°=スピナー寄り(奥まで滑ってから強く曲がる・総フック量が増える)。

42°

縦方向の軸の傾き。0°=フラットで丸い弧を描く / 大きいほど切れ際まで溜めてから角のある鋭い動きになります(42°はThrow Analyzerで計測されたあなたの実測値をデフォルトにしています)。

使い方

1. メイン画面の「立ち位置」と「狙うスパット」でラインを決める(破線=予測ライン、緑の照準=狙っているスパット)。

2. レーン全体図を指でなぞると、「立ち位置」はそのままに、なぞった点(フッキングポイント)を必ず通るよう投げる角度を計算します(その時点のスパットの値は使いません)。

3. 「投げる」でボールが転がり、ピンデッキ手前からは物理演算でボールとピンが実際に衝突・連鎖します。「リセット」でピンを立て直し。

4. レーンが変わったら「セット」でオイルや利き手を調整。「記録」で実際の練習をカレンダーに残せます。

実寸準拠: レーン幅41.5in(39枚) / 1番ピンまで60ft / ピン間隔12in / ピン径4.77in / ボール径8.5in / ガター幅9.25in。全体図は見やすさのため横方向のみ拡大表示できます(縦横比以外の寸法関係は実寸)。薄いピンク帯=ボールの通過幅、緑の照準=狙っているスパット(15ft)、◯=ブレイクポイント、破線円=ポケット。

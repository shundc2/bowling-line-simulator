# ボウリング ラインシミュレータ

スマホで使えるボウリングのラインシミュレータです。立ち位置・狙うスパット(またはフッキングポイント)・オイルパターン・ボールの性能から、投球ラインとピンアクションを確認できます。

**作成者: Shun＆Claude**

## 使い方

公開URL(GitHub Pages)をスマホのブラウザで開くだけで使えます。
「ホーム画面に追加」するとアプリのように使えます。

> URL: `https://(ユーザー名).github.io/(リポジトリ名)/`

## 主な機能

- 右投げ / 左投げ対応(板の番号は投げ手から数えて表示)
- 立ち位置・狙うスパット・フッキングポイント(レーンをタッチ/なぞって指定)
- オイルパターン(クラウン・フラット・ブロック)とオイル量
- ボール設定(重さ・カバー・RG・フレア・回転数・軸回転・軸の傾き)・投球スピード
- 実寸に近いレーン・ピン・ボール・アローの比率
- 物理演算によるピンアクション
- セッティングの助言(この位置でストライクを狙うには?)
- 練習記録(日付・場所・レーン番号・ボール・感想・写真4枚まで)をカレンダーで管理

## データの保存について

練習記録と写真は、お使いの端末のブラウザ内(localStorage)にだけ保存されます。サーバーには送信されず、他の端末や他の人とは共有されません。ブラウザのデータを消去すると記録も消えるのでご注意ください。

## 注意事項

- 実際のレーンの状態(オイルの量・摩擦・ボールの個体差など)との差があります。あくまで目安としてお使いください。
- 実際の投球データをもとに調整していますが、結果を保証するものではありません。
